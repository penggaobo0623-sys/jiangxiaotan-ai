# 江小摊 AI——校园小吃摊智能经营助手

比赛源码仓库。**完整项目源码位于 `jiangxiaotan-ai-source.zip`**，包含前端、后端、Windows启动脚本、自动化测试及项目文档。网页批量上传目录未成功，因此以源码压缩包提供，不是在线运行的网站。

## Windows运行

1. 点击 `jiangxiaotan-ai-source.zip`，下载后解压到独立文件夹；不要直接在压缩包内运行。
2. 安装Python 3.10+（推荐3.12）及Node.js 24 LTS或22.12+。
3. 双击 `setup.cmd` 安装依赖。
4. 双击 `demo.cmd`，在本机浏览器打开 `http://127.0.0.1:5175/`。演示默认使用模拟模型，不需要密钥，不产生模型费用。
5. 日常空账本使用 `start.cmd`，本机地址为 `http://127.0.0.1:5173/`。保留启动窗口，按Ctrl+C停止。

仓库不携带原电脑账本、模型密钥、真实环境配置、备份或日志。演示脚本会新建独立虚构样本；视频中的扩展菜品场景与默认脚本场景金额不同，均不是商家经营成效。localhost仅供运行项目的电脑访问，不能当作公网网站链接。

## 功能与边界

- 商品管理、销售价格/成本快照、每日收摊、营业状态、历史编辑与删除恢复。
- 整数分计算的经营看板；缺失日期不当零销售，估算结余不是实际净利润，销售记录条数不是订单数。
- 后端经营摘要、可替换模型连接、结果校验、明确标注的本机基础分析。
- 主动生成、编辑和复制营销草稿；不自动发布，不编造优惠或顾客口碑。
- DeepSeek官方连接已实现；新版自然表达仅模拟验证，本次发布没有付费模型请求。使用真实模型前在后端本机配置，不要把密钥提交仓库或放入前端。
- 此前项目检查：163项Python、3项前端金额测试、TypeScript及生产构建通过。真实手机、商家经营成效和新版真实模型表达仍待验证。

完整操作、架构和测试说明在源码包内的 `README.md`、`ARCHITECTURE.md`、`TESTING.md`。本仓库用于提交代码链接；PPT与视频由参赛者在赛事入口分别提交。
